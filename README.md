# ESI 2CS SID Machine Learning Labs

## Overview

This repository encompasses a series of laboratory exercises from the second-year Computer Science program at the Ecole Nationale Supérieure d'Informatique (ESI), Algiers. The labs delve into fundamental machine learning concepts and algorithms, providing practical experience with various ML techniques.

## Repository Structure

The repository is organized into directories, each corresponding to a specific lab:

- `Lab01/`: Introduction to machine learning, basic algorithms, and datasets.
- `Lab02/`: Supervised learning algorithms, including regression and classification techniques.
- `Lab03/`: Unsupervised learning, including clustering and dimensionality reduction techniques.
- `Lab04/`: Advanced machine learning topics, such as neural networks and deep learning.
- `Lab05/`: Model evaluation, cross-validation, and performance metrics.
- `Lab06/`: Application of machine learning techniques to real-world datasets.

Each lab directory contains:

- **Jupyter Notebooks**: Implementations of various machine learning algorithms and techniques.
- **Explanatory Materials**: Detailed instructions and explanations of the concepts covered.
